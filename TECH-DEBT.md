# Tech-Debt Ledger

Deliberate shortcuts taken to ship faster, each with the target state it deviates from and a
**paydown trigger** — the concrete condition that means "now fix it." A shortcut recorded here is
a decision; one that isn't is rot.

Untriggered debt is how "temporary" becomes forever — every entry needs a paydown trigger.

## How to read an entry

- **Shortcut** — what we did instead of the clean way.
- **Why** — the time-to-market reason it was the right call now.
- **Target state** — the spec-ideal version it deviates from.
- **Paydown trigger** — the event/threshold that flips this from "fine" to "fix it now."
- **Story** — the backlog story that incurred it.
- **Status** — `open` | `paid`.
