# 08 — Ad-hoc & Improvements

The open bucket for work that doesn't belong to a planned epic — small improvements, one-offs, and
candidate ideas not yet sequenced. `tech-planning` creates a story file here when the work fits no
existing epic. Never invent a parallel planning system. Reuse this.

Prioritize candidates via the value model (CLAUDE.md §3). Promote one into a real epic when it earns
its place.
