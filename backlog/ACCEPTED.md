# Accepted

Decisions that have been **made** but haven't yet been turned into an approved `tech-planning` story —
settled calls with nowhere to live yet: no story exists for them, and no epic README has absorbed them
as settled epic-level shape.

**Not status** — there's no story, branch, or build state to report on an entry here.
**Not a queue** — nothing here is scheduled or ordered; an entry can sit for a day or a quarter before
it's routed.

> An entry clears only by **routing** it somewhere real: into `tech-planning` as a new story, or into
> an epic's `README.md` as settled epic-level shape. That's the only way out — an entry is never
> deleted and never summarized down. When it moves, its reasoning moves **verbatim** to whatever file
> now owns it; a one-line pointer stays behind here, moved from **Open** to **Cleared**.
